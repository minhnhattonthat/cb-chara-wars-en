# Glossary - CB Chara Wars: Ushinawareta Gag (SNES, 1992)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Table rows are lint-enforced (tools/lint.py): if the JP cell occurs in a line, the EN cell must occur in its English;
spellings in the Avoid column fail the check.

## Rulings (asked of the user once, 2026-10-11)
- Honorifics: dropped. Name order: Western (Koji Kabuto, Ryo Asuka).
- Romanisation source: official / anime-OVA / established English Go Nagai names first, else Hepburn without macrons.
- Credits: English.
- Register / flavour: comedy crossover; keep gag punch over literal meaning. Sound effects: plain words ("Gyaaah!!").
- Abbreviations: none; full names and terms everywhere, prefer engine changes over shortening.
- Specs/plans: pre-approved; report after, user playtests.

## Style rules
- Dialogue box: 28 columns, 4 lines per page, auto-wrapped by the build. `{n}` forces a line break, `{p}` a new page.
- Punctuation map: "..." (JP quotes) -> "...", ・・・ -> ..., ！！ -> !!, ？ -> ?. No *, $, %, @ or \ (no glyph).
- ♥ exists in the font and may be kept where the JP has it.
- `{fd:XX}` = typing speed (04 normal; 09 followed by a space = a dramatic pause). Keep them at matching beats.
