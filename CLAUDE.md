# CB Chara Wars: Ushinawareta Gag (SNES, Banpresto 1992) English translation

Skill: translate-retro-game (H:/translation/cb-chara-wars/.claude/skills/translate-retro-game/SKILL.md). Read it before ROM, text or QA work.

## Commands (run from repo root)
- Build:    `python -X utf8 build.py` -> build/cbcw_en.sfc (`--marker` = id markers for QA)
- Check:    `python -X utf8 tools/check.py` (lint + pytest: roundtrip, coverage, identity build; pre-commit runs it)
- Smoke:    `python -X utf8 .claude/skills/translate-retro-game/scripts/emu.py build/cbcw_en.sfc --out work/qa/smoke --route tools/routes/shop1.txt --smoke`
- Release:  `python -X utf8 tools/release.py --version X.Y` -> dist/CBCharaWars_EN_vX.Y.zip (bps + README). Never publish without the user.
- Text:     `tools/text.py dump|roundtrip`, `tools/batches.py split|check|merge|pairs`, `tools/wrap.py "<en>"` (box preview),
            `tools/menus_en.py` / `tools/items_en.py` (menu/item English live there, re-run to write JSON), `tools/testmsg.py IDS "<en>" out.sfc`.

- English build: dialogue in bank $20 (2 MiB ROM), BOTH engine copies patched ($06:B8D7 field, $07:E5C7 shop). Items move into the freed bank 07 script area.
- Two dialogue windows: wide (28x4, table 8BCA + intro) and portrait/shop (18x5); 8D4A messages wrap to 18x4 (box chosen at runtime). See tools/wrap.py.
- Fixed frame routes drift when text length changes: wait on screens, not frame counts.
